# Find the Odd Color

A simple JavaScript game where the player has to find the square with a slightly different color.

## Live Demo

[Play the game](YOUR_DEMO_LINK_HERE)

## Features

- 16 squares with randomly generated colors
- One randomly selected square has a slightly darker color
- The color difference decreases as the score increases
- Increasing difficulty as the score gets higher
- Displays the current score
- Displays the user's high score
- High score is saved in Local Storage and persists after refreshing or reopening the browser
- Game Over screen when the player selects the wrong square
- Restart button to start a new game

## Technologies

- HTML5
- CSS3
- JavaScript
- Local Storage

## How to Play

1. Find the square with the different color.
2. Click on the different square.
3. If your answer is correct, your score increases and the game becomes harder.
4. If you select the wrong square, the game ends.
5. Click the restart button to play again.

## Purpose

This project was created as a JavaScript practice project to work with DOM manipulation, random values, event handling, functions, conditional logic, dynamic styling, and Local Storage.
